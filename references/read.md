# 论文速读

从输入确定范围和深度。已有完整材料就直接读。保留用户指定的每一篇；领先展示对当前问题最有帮助的工作，用户指定顺序时沿用。默认中文 Markdown，每篇在同一处放解读和双语摘要。

以原题名为标题。开头两三句话回答“做了什么、最有判断价值的证据是什么、为什么值得我读”。选择真正会改变阅读决定的条件，如是否跨设备测试、基线是否可比。把作者主张和已展示的证据说清，避免将任务、动机和贡献重复填成数栏。

随后给英文摘要和对应中文。用户提供或许可允许复制的原摘要可以保留并标为原文，其他情况给英文释义和对应中文。缺摘要时说明材料现状。出处、DOI、实际核读版本或章节放在篇末，默认用纯文本。仅给题名时保留为待核线索。

需要精读时再展开问题、设计、关键实验和局限。数字跟随其数据集、划分和指标；跨论文比较先对齐任务和条件。只读过摘要就标明“依据摘要”。读者要全局判断时，最后合并真正可比的结论，点出最值得下一步核查的证据。
