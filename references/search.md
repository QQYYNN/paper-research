# 检索与筛选

先用一句话明确用户想找到什么，抓住研究对象、实际输入和要解决的问题。检索词用领域里的说法和同义词。给定会议时优先查正式论文集，默认取主会；年份以正式书目为据。主题、单位或类别限制按用户实际指定执行。

第一轮优先使用已有书目和可靠来源。以 DOI 或正式记录去重，核对题名、年份、venue 和摘要；按与问题的直接程度、证据是否回答关键疑问、是否带来不同视角排序。最前面写出这批论文已经做到什么，以及最值得先读哪篇、为什么。每篇展示原题名、发表信息、一句阅读理由和可回查的标识。只有题名的线索注明“待核”。用户给了数量上限时可以少选。探索任务到读者足以决定下一步时即可交付。

例如关注跨日期的无人机个体识别时，优先找预测标签为具体设备、训练与测试跨采集日的研究。只有机型分类的工作在能借鉴数据或协议时列为相邻工作。判断依赖某个细节时，只查能解决问题的段落或实验表。

按需加深：
- 两主题盘点可按仅 A、仅 B、A×B 分组。交叉项须在主要任务、输入或贡献中同时涉及两者。
- 指定穷举、计数或以缺失论证研究空白时，枚举官方目录，扩大到摘要检索、索引补检和相关引文。记录覆盖范围、检索日期、纳入、排除与待核，报告尚未覆盖的部分。
- 要求建库或下载时保存去重记录及可用开放版本，核对 PDF 首页与书目。阶段间传递原题名、稳定标识、venue/年份、摘要或摘录及出处，同时携带用户的研究问题。
